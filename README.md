# FolderIcon · 桌面文件夹面板

**像手机文件夹一样，点开桌面入口，内容就地展开。**

原生Win32 · 三类入口统一管理 · 单击打开 · 多显示器跟随

[English](README.en.md) · [下载与发布](https://github.com/yumumao/FolderIcon/releases) · [更新说明](docs/RELEASE-v2.0.0-rc.3.md) · [验证范围](docs/VALIDATION.md)

FolderIcon把常用文件夹变成轻量弹出面板。你可以给任意位置的文件夹创建桌面入口，也可以让**桌面已有的真实文件夹原地展开**，无需移动、替换或删除原目录。

本仓库是[ltrudu/FolderIcon](https://github.com/ltrudu/FolderIcon)的独立中文增强Fork，不是上游官方发行版。当前发布线为**v2.0.0-rc.3公开预览**；程序界面为简体中文，文档提供中英文。支持目标为Windows10/11 x64，目前实机验证环境为Windows10。README复用已审核的点击展开示意、面板／设置／退出确认演示截图，以及两张经用户授权、名称已脱敏的真实目录截图。首图复用已审核入口图案和真实面板，桌面选择框、鼠标及快捷方式箭头为示意，不是完整桌面截图；真实面板未重绘。设置中的演示路径作了简化显示；真实截图的面板标题及条目名称均已遮蔽，不展示个人路径。

> **rc.3更新**：新增右键打开方式选择；蓝、橙、绿三类入口集中到选项卡管理；绿色箭头向中心调整；绿色单击松开即发起打开，不等系统双击；新窗口和本次唤起的旧窗口跟随图标所在屏幕。详见[更新说明](docs/RELEASE-v2.0.0-rc.3.md)和[桌面打开方式](docs/DESKTOP-MODES.md)。rc.1／rc.2标签及附件保留。

## 一分钟开始

1. 从[Releases](https://github.com/yumumao/FolderIcon/releases)下载`FolderIconCN-v2.0.0-rc.3-win-x64.zip`，解压到一个可写、准备长期保留的位置。不要在压缩包内直接运行。
2. 打开`FolderIconCN.exe`进入设置。首次打开不自动启动后台，也不自动添加开机启动或右键菜单。
3. 点击**管理桌面入口…**，在蓝色选项卡添加文件夹、创建桌面入口；也可在橙色选项卡添加桌面真实文件夹，或在绿色选项卡添加桌面文件夹／快捷方式。
4. 在管理窗口中添加、删除选中、重加角标或更改打开方式。原文件夹留在原处，新建蓝色入口指向原目录。
5. 要使用桌面单击展开、单击打开和多显示器跟随，请在设置里点击**启动后台**。需要内置开机自启时，另外勾选**开机静默启动**并保存；已有Startup快捷方式可以继续使用，无需重复勾选。

> 已经在用旧版？先退出监听，备份整个程序目录，再替换EXE。**不要覆盖已有`FolderIcon.ini`，也不要删除`icons/`、`folder-badges/`、`mode-backups/`、`desktop-modes.ini`或排序文件来完成升级。** 保留程序位置，避免已生成快捷方式找不到EXE。发行包仅提供示例配置，不携带任何个人配置。

## 三类桌面入口，怎么选？

| 类型 | 添加什么 | 后台运行时 | 删除选中的含义 |
| --- | --- | --- | --- |
| 蓝色四格：面板快捷方式 | 任意文件夹的新桌面入口，或已有文件夹快捷方式 | 单击展开面板 | 自建入口删除生成的链接；已有链接恢复默认，原目录保留 |
| 橙色四格：原位展开 | 桌面第一层真实文件夹 | 单击原位展开面板 | 撤销展开设置，恢复原图标，保留文件夹 |
| 绿色箭头：单击打开 | 桌面第一层真实文件夹或`.lnk`快捷方式 | 松开即打开；窗口跟随图标所在屏幕 | 恢复原点击方式和原图标，保留项目 |

蓝、橙四格和绿色箭头沿用相同的右上位置、圆角与白描边。**不会全局关闭Windows的快捷方式小箭头**，也不需要安装图标覆盖扩展。没有后台时，新建的蓝色专用快捷方式仍可按Windows点击方式展开面板；普通链接和真实文件夹沿用系统原行为。

### 设置入口与桌面位置

设置 → **管理桌面入口…**打开三个选项卡，分别提供添加、删除选中、重加角标和更改打开方式。橙色只列出桌面第一层真实文件夹；绿色支持真实文件夹与快捷方式，软件／文件快捷方式只能直接打开。

- 管理操作立即生效，关闭管理窗口或取消主设置不会撤销已完成的操作。删除时会说明范围；前三个内置蓝色入口保留。
- 外观、开机启动和桌面位置需保存并应用。主设置中的外观草稿不会因打开管理器丢失；更改桌面位置后，先保存再管理入口。
- 桌面默认采用Windows实际位置。可指定桌面位置或恢复自动识别；这只改变FolderIcon管理范围，不迁移文件、不修改Windows桌面，也不接管任意资源管理器窗口。

下方保留的设置外观截图来自rc.2；rc.3入口管理已改为上述独立选项卡窗口。

## 文件夹里还能继续展开

对面板中的真实子文件夹右键，勾选**在面板内展开**即可。已设置的子文件夹显示角标；未设置的仍交给资源管理器，不会把所有目录自动接管。

<img src="docs/images/subfolder.png" width="460" alt="子文件夹展开后的面板，左上角有明显的返回按钮">

- 子层级左上角有明显的**返回**按钮。
- 在子层级**双击面板空白处**也可返回上一级；根层不会越级跳出。
- 对子文件夹右键，可取消继续展开，或临时在资源管理器中打开。
- 文件和普通快捷方式依然交给其默认程序打开。

## 换了图标，蓝色角标怎么补回来？

1. 按Windows原有方式，在快捷方式属性里换成你喜欢的图标。
2. 打开FolderIcon设置，进入**管理桌面入口… → 蓝色**，选中这个入口。
3. 点击**重加角标**并确认，即刻生效。

软件会读取快捷方式**当前的图案**，生成一份独立的带角标图标，再更新快捷方式。不恢复成默认图案、不改动原始ICO，也不修改源文件夹图标。支持ICO及DLL/EXE图标资源；重复点击不叠加多层角标。若自定义图标无法读取，会报错，不会悄悄换成默认图标。

## 删除入口与自动清理

- 从设置删除已生成入口，或直接在桌面删除展开快捷方式，均**不删除真实源目录**。
- 后台监听利用目录变更通知，等待变更稳定后核对失效入口；空闲时不反复枚举目录，不扫描全盘。
- 没有后台时，下次打开设置也会核对。可随时点击**清理失效配置及孤立角标**手动执行。
- 只清理失去有效快捷方式的自选入口，以及本工具有恢复记录、又没有有效引用的历史目录角标；不会顺带删除你明确设置的文件夹展开规则。
- 改名或同一桌面范围内仍有有效副本时保留入口；目录离线、快捷方式不可读或枚举不完整时保守保留。
- 用户后来又改过目录图标时，不强行覆盖。部分生成的ICO会保留为恢复资产，避免其它位置复制的快捷方式断图标。

## 可选右键打开方式

在设置中勾选**在文件夹和快捷方式右键菜单中添加FolderIcon打开方式…**并保存，即可右键桌面项目，选择**FolderIcon打开方式…**：

- **展开面板**：真实文件夹或指向文件夹的快捷方式单击展开。
- **单击直接打开**：按原快捷方式参数启动或在资源管理器打开目录，右上加绿色箭头。
- **恢复默认**：撤销该项目的模式，恢复原图标。设置后被外部修改的快捷方式会提示冲突并保留恢复材料。

对话框显示当前模式；软件、文件快捷方式禁用面板选项。只支持当前桌面第一层的真实目录与`.lnk`，普通文件可先创建快捷方式。此电脑、回收站和其它虚拟图标不在本轮范围。

单击需要后台运行。绿色项目松开鼠标即发起打开，不等待系统双击；快速连续点击只打开一次，第二击不另作动作。直接按住拖动、右键和Ctrl／Shift多选保持原样。桌面外的真实文件夹继续提供创建桌面展开入口的操作。菜单为当前用户级，不安装常驻Shell扩展；Windows11的完整交互仍待实机验收。

绿色入口支持多显示器跟随：图标在哪块显示器，本次新开或唤起的窗口就移到那块显示器。保留正常窗口大小和最大化／最小化状态；窗口大于目标屏幕可用区域时会缩小以保持可见。只定位本次打开的窗口，不持续固定位置。第三方启动器、管理员窗口或无法可靠识别的窗口可能仍由原程序决定位置，详见[桌面打开方式](docs/DESKTOP-MODES.md)。

## 外观、排序与操作

设置中直接显示当前后台状态，开机启动单独勾选；图标大小等参数右侧的浅蓝说明卡提示退出后台后的区别。

<img src="docs/images/settings-appearance.png" width="840" alt="rc.2设置：图标大小、网格、独立开机启动选项、后台按钮和退出后台说明卡">

- 图标与网格可以跟随桌面，字号也可独立跟随；也能手动设置大小、列数、间距。
- 支持背景颜色、不透明度、圆角。当前使用**单层半透明背景，不实时磨砂**，避免双层窗口导致圆角异常。
- **右键面板 → 排序与整理…**，设置当前文件夹的排序方式、方向与自定义排列；支持拖动整理。
- 点号开头的项目默认按隐藏项处理；可选择显示隐藏文件及系统隐藏项。
- 面板内单击项目打开；滚轮翻页；Esc或点击外部关闭。
- 设置窗口可拉宽，双列和按钮随宽度调整，并设最小宽度；窗口较矮时向下滚动可见保存按钮。

### 后台启停与开机启动

不再需要选择按需或增强模式；后台是否运行就是当前状态。

| 操作 | 行为 |
| --- | --- |
| 直接运行EXE或`--settings` | 始终打开设置，与后台状态无关 |
| 设置里点击启动后台，或运行`--resident` | 立即启动共用监听；`--resident`不弹设置，也不检查旧模式开关 |
| 退出后台，或运行`--stop` | 只结束本次监听，不修改开机启动；生成入口仍可按需打开，真实文件夹恢复Windows原行为 |
| 保存开机静默启动选项 | 只管理本程序的登录Run启动项，不启动或停止当前监听 |

**启动文件夹中已有的快捷方式无需修改**：保持原EXE路径及`--resident`即可。手工Startup快捷方式与内置Run启动项是两种启动来源，任选一种即可；取消内置选项不会删除手工快捷方式，如需完全取消自启，还需在Windows启动文件夹中管理自己的快捷方式。

旧配置`Resident`仅在缺少`AutoStart`时迁移为开机启动偏好；它不再决定能否启动后台。保存时写入`AutoStart`，同时保留旧键兼容旧版。托盘保留设置和退出后台，不再提供模式切换。设置参数右侧会说明退出后的行为：专用快捷方式仍可双击展开面板，真实桌面文件夹不再监听单击。通过设置或托盘退出时会再次显示这段说明并要求确认，默认取消；退出不改变开机启动。

<img src="docs/images/exit-confirmation.png" width="680" alt="退出后台确认：专用快捷方式仍可双击展开，真实文件夹不再监听，默认取消且不改变开机启动">

面板默认展开等待80毫秒；绿色单击直接打开不受该设置控制，也不等待Windows双击判定。实际打开速度仍会受系统负载、Shell及目标程序启动耗时影响。

## 轻量，但不夸大数字

原生C++/Win32实现，不使用Electron、WebView或.NET运行时；不要求管理员权限。rc.3发布EXE为441856字节，约431.5KiB；不同工具链构建大小可能变化。

此前rc.1在2026-10-12的Windows10后台空闲采样（不是rc.3重新测量）：工作集约**14.24MiB**、私有内存约**3.89MiB**；15秒内未测得CPU时间增长。**这是一次短时测量，不是内存上限或长期零CPU承诺。** 图标加载、面板打开及大目录会有不同开销。详见[验证范围](docs/VALIDATION.md)。

## 命令行

```powershell
.\FolderIconCN.exe                           # 打开设置
.\FolderIconCN.exe --settings                # 打开设置
.\FolderIconCN.exe --folder "$env:USERPROFILE\Documents"
.\FolderIconCN.exe --resident                # 显式静默启动后台，不受旧模式配置限制
.\FolderIconCN.exe --stop                    # 仅停止本次监听，不删除自启
```

`--entry <ID>`用于生成的入口；保留兼容的`work`、`coding`、`services`三个内置ID。新增入口由设置自动管理，不需要手工编辑INI。`--diagnose <输出.json>`用于生成开机启动偏好及桌面尺寸诊断，不列出文件内容；诊断文件仍建议只在本地保留。

## 从源码构建

已验证路径：Windows x64 + PowerShell7 + **Zig0.13.0**。编译器需自行安装，脚本不会自动下载依赖。

```powershell
.\scripts\build.ps1 -Zig 'zig' -BuildRoot '<构建目录>' -OutputDirectory '<成品目录>'
.\scripts\build.ps1 -Zig 'zig' -BuildRoot '<构建目录>' -TestsOnly
```

脚本运行测试后构建`FolderIconCN.exe`；构建目录承载TEMP/TMP与Zig缓存。不会覆盖个人INI和图标。CMake也提供`FolderIconCN`与测试目标，但MSVC/CMake路径尚未在本机完整验证：

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

`main.c`、旧`.sln`与`.vcxproj`保留上游实现；它们**不是当前中文版的构建入口**。GitHub工作流改为调用上述中文版构建和测试脚本，上传工件，不自动将旧版C程序发布为中文版。

## 数据与退出使用

配置保存在EXE旁的`FolderIcon.ini`，图标、目录角标恢复记录、缓存和排序文件也存放于程序目录。软件不内置遥测、账号、联网更新或云同步。

如果不再使用：先对单独设置过打开方式的项目右键恢复默认，再在设置里取消真实文件夹展开规则、删除生成入口并清理孤立角标，再关闭右键菜单和内置开机启动、处理自己添加的Startup快捷方式，最后退出后台。**完成恢复前不要先删程序目录里的`folder-badges/`、`mode-backups/`和`desktop-modes.ini`**。无法访问的目录或图标冲突应先处理完，再移除恢复数据。
